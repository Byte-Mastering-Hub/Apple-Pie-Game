# 🍎 Apple Pie

A fun word-guessing game built with **Swift and UIKit** for iPad. Guess the hidden word before the Apple Pie runs out!

## 🛠️ Built With

* Swift
* UIKit
* Xcode
* iPadOS

## 🎮 How to Play

Guess the hidden word by selecting letters.
Each incorrect guess removes a piece of the Apple Pie. Guess the word before the pie runs out! 🍎
